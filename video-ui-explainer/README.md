# video-ui-explainer

Plantilla Remotion para vídeos verticales estilo "UI explainer" (tarjetas animadas + subtítulos palabra a palabra).
Guía completa: `.claude/skills/video-ui-explainer/SKILL.md`.

```bash
npm i
npm run dev                                        # Remotion Studio
npx remotion render CanalMillon out/canal-millon.mp4
```

Ejemplo de guion: `src/scripts/ejemplo-canal-millon.ts`. Vídeo de ejemplo renderizado: `../media/ejemplo-ui-explainer.mp4`.
